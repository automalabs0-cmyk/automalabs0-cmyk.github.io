# MIND lector — página pública

Repositorio exclusivo para la página principal y la política de privacidad de **MIND lector**, la app OAuth de escritorio
(uso personal) que lee en solo lectura una carpeta de Google Drive para el diario personal MIND.

- `index.html`: página principal (enlaza la política).
- `privacidad.html`: política de privacidad.
- `estilo.css`: estilos.
- `.nojekyll`: GitHub Pages sirve los archivos tal cual.
- El archivo de verificación de Google Search Console (`google<código>.html`) se añade cuando Search Console lo genera.

No contiene datos personales, credenciales ni código de MIND.

Para publicar: repositorio público llamado `<usuario>.github.io` → GitHub Pages desde la rama `main`, carpeta raíz.
